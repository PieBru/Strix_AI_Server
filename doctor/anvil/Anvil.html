MCP servers
Browsers can't spawn stdio processes, so a server must speak Streamable HTTP or SSE over HTTP(S), or you can bridge a stdio server to WebSocket/SSE with a small local proxy (e.g. mcp-proxy / supergateway). Cross-origin servers need CORS enabled here too — or set the server's CORS proxy field to your llama-server's /cors-proxy (e.g. http://127.0.0.1:8080/cors-proxy, requires --webui-mcp-proxy): the server makes the request for you, so CORS-hostile MCP endpoints like mcp.tavily.com work. The legacy SSE transport can't send custom auth headers (a browser EventSource limitation) — use Streamable HTTP if the server needs a bearer token.
